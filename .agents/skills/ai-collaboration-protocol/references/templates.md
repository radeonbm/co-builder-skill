# Protocol templates

Use these as compact, editable prompts—not rigid forms. Omit fields that would add no decision value.

## Conversation opening

```markdown
Tell me what you are thinking about or trying to make—an unfinished idea is enough.
I will start by understanding the direction and help you find the best next move.
```

After the reply, lead with a tentative understanding and a concrete next move. Ask only the single question whose answer most changes that move.

## Working brief

```markdown
Working brief
- Vision (human-owned): …
- Confirmed facts — user-confirmed | agent-verified: …
- Temporary assumptions (reversible): …
- Boundaries (shared): …
- Current move (agent-maintained): …
- One open question, if needed: …
```

Keep this concise and internal by default. Use a plain-language recap only at a meaningful transition or when the user needs to correct it.

